# Code of conduct

Be respectful in issues, pull requests, reviews, and other project discussions.
People with different backgrounds and levels of experience are welcome.

- Discuss the code and the problem. Give specific, constructive feedback.
- Respect disagreement, boundaries, and maintainers' time.
- Do not harass, threaten, discriminate, or make personal attacks.
- Do not publish another person's private information without permission.
- Do not post spam or sexual content unrelated to the project.

Maintainers may edit or remove inappropriate content, close discussions, or limit
participation. They should explain moderation decisions when doing so is practical
and does not expose private information.

Flag inappropriate public comments to the repository maintainers using GitHub's
moderation controls. For abuse that needs a private report, use GitHub's
[Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
tools. Those private reports go to GitHub, not to the project maintainers. Do not
post personal details publicly to explain a conduct concern.
